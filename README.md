# Azure RBAC Simulation Example

This example demonstrates the core concept of Azure Role-Based Access Control (RBAC) through a simple Python simulation. It defines resources, actions, roles, and users, then checks if a user has permission to perform a specific action on a resource based on their assigned roles. This illustrates how access is managed by assigning roles with predefined permissions, aligning with the article's emphasis on understanding fundamental principles rather than memorizing portal steps.

## Language

`python`

## How to Run

Save the code as `rbac_simulator.py`. Open a terminal or command prompt, navigate to the directory where you saved the file, and run `python rbac_simulator.py`.
